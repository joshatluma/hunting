I work in venture capital and build AI skills for the work I do every day: researching companies, thinking through opportunities, and making better decisions.

This is where I’m sharing them.

## Skills

- [High-Leverage Job Hunt](./high-leverage-job-hunt) — Find your edge, identify companies where it matters, and turn conversations with founders into opportunities.

## Get started

Just send this to Claude Code, Codex, or another agent with terminal access:

> Install the skills from https://github.com/paulklayvc/skills and set them up for this agent.

Your agent can handle the setup for you.

### Prefer the terminal?

```bash
npx skills add paulklayvc/skills
```

Choose your agent during setup. Add `-g` to install across all your projects.

Once installed, ask your agent to use `high-leverage-job-hunt`.

Use them, adapt them, and make them your own.
